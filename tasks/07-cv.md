## 1. Analisis Dataset (dokumentasi preprocessing sudah disetujui)

> Ringkasan keputusan analisis (dokumen lengkap disimpan sebagai catatan fase ini):

- [ ] **RGB 8-bit sRGB — tanpa grayscale.** Warna rambut = parameter kunci konsultasi (risiko smoothing/rebonding pada rambut bleaching/kering).
- [ ] **Ruang warna**: RGB untuk input model; **HSV** untuk atribut warna dominan; **YCbCr (kanal Y)** untuk kontras tanpa ubah warna.
- [ ] **Resolusi standar internal**: resize keep-aspect → sisi-terpendek **256 px** → **center-crop 224×224** (native MobileNetV2). Jangan resize non-uniform (distorsi panjang rambut); buang/flag gambar <224 px.
- [ ] **Kontras**: **CLAHE pada kanal Y/V** (clip 2.0, tile 8×8) OPSIONAL — global Histogram Equalization DILARANG (merusak nilai warna absolut deteksi bleaching).
- [ ] **Segmentasi (ROI)**: default **Otsu** pada `Y`; naik ke **Adaptive Thresholding** (block≥51, C≈2) bila bayangan lokal tidak seragam.
- [ ] **Opsi 3 hibrida**: ekstraksi deskriptor **HSV stats** (Hue/Saturation/Value→lightness) + **GLCM** (contrast, entropy≈gloss) sebagai `hair_features.json` → konteks LLM (`/consult`). Tanpa label baru.
- [ ] **Open items saat dataset tersedia** (isi placeholder): resolusi min/max/avg, format & bit-depth aktual, profil histogram per kelas (bimodal/underexposed), distribusi label.

## 2. Skrip Offline Python — `apps/api/cv/scripts/`

- [ ] `analyze_dataset.py` — statistik dataset: resolusi min/avg/max, format & bit-depth, distribusi per kelas, **profil histogram** + deteksi bimodal + mark Otsu `T*`; output `apps/api/cv/reports/dataset_report.json` + PNG.
- [ ] `preprocess.py` — pipeline training terstandar (EXIF orient → 8-bit sRGB → CLAHE-Y opsional → resize 256 → center-crop 224 → augmentasi §3 → normalisasi ImageNet → tensor NCHW).
- [ ] `extract_features.py` — deskriptor HSV + GLCM (Opsi 3 hibrida) → `hair_features.json`.
- [ ] `export_to_onnx.py` — training script + export 2 head MobileNetV2 (length + type) → `apps/api/cv/weights/hair_length.onnx` & `hair_type.onnx`.
- [ ] `apps/api/cv/weights/` **di-gitignore** (artefak besar); env: `MODEL_LENGTH_PATH`, `MODEL_TYPE_PATH` (default `./cv/weights/...`).

## 3. Data Augmentation (Spatial Invariance)

- [ ] **Random Resized Crop** (scale 0.875–1.0, aspect 3/4–4/3) — solusi utama posisi/skala objek bervariasi.
- [ ] Random Horizontal Flip (p=0.5), Rotasi ±10°.
- [ ] Affine ringan (translate ±10%, shear kecil).
- [ ] Fotometri: brightness/contrast ±10%; **hue jitter kecil ±0.02 (HSV)** (tahan AWB, tanpa mematikan makna bleaching).
- [ ] Cutout 2–4 patch kecil (optional).

> Di sisi **inference**: normalisasi & resize SAMA PERSIS dengan training (256→224 + ImageNet) — tanpa augmentasi. Ini wajib agar akurasi train/inference konsisten.

## 4. Integrasi Backend — `CvService.ts`

- [ ] Decode gambar (buffer) + auto-orient EXIF → preprocessing pipeline (Node-side: resize, center-crop, normalisasi).
- [ ] Inference via **`onnxruntime-node`** (sudah ada di `package.json` ^1.20.1): feed tensor float `NCHW 1×3×224×224` → logits → softmax → label + confidence.
- [ ] Label mapping tetap (PRD): panjang `{pendek, pendek-menengah, menengah, panjang}` · jenis `{lurus, bergelombang, keriting, sangat-keriting}`. Nama kelas RUPANYA tidak boleh berubah.
- [ ] `CONFIDENCE_THRESHOLD` (default 0.5) → hasil `low_confidence`.
- [ ] Ekstraksi `hair_features` (HSV+GLCM) digabung ke respons `AnalyzeResponse`/konteks.
- [ ] `POST /api/analyze` mengembalikan hasil asli (menggantikan stub), rate-limited.
