## 1. Analisis Dataset (dokumentasi preprocessing sudah disetujui)

> Ringkasan keputusan analisis (dokumen lengkap disimpan sebagai catatan fase ini):

- [ ] **RGB 8-bit sRGB — tanpa grayscale.** Warna rambut = parameter kunci konsultasi (risiko smoothing/rebonding pada rambut bleaching/kering).
- [ ] **Ruang warna**: RGB untuk input model; **HSV** untuk atribut warna dominan; **YCbCr (kanal Y)** untuk kontras tanpa ubah warna.
- [ ] **Resolusi standar internal**: resize keep-aspect → sisi-terpendek **256 px** → **center-crop 224×224** (native MobileNetV2). Jangan resize non-uniform (distorsi panjang rambut); buang/flag gambar <224 px.
- [ ] **Kontras**: **CLAHE pada kanal Y/V** (clip 2.0, tile 8×8) OPSIONAL — global Histogram Equalization DILARANG (merusak nilai warna absolut deteksi bleaching).
- [ ] **Segmentasi (ROI)**: default **Otsu** pada `Y`; naik ke **Adaptive Thresholding** (block≥51, C≈2) bila bayangan lokal tidak seragam.
- [x] **Opsi 3 hibrida**: ekstraksi deskriptor **HSV stats** (Hue/Saturation/Value→lightness) + **GLCM** (contrast, entropy≈gloss) sebagai `hair_features.json` → konteks LLM (`/consult`). Tanpa label baru. *(ekstraksi script belum, lihat §2)*
- [x] **Open items saat dataset tersedia**: resolusi min/max/avg, format & bit-depth aktual, profil histogram per kelas (bimodal/underexposed), distribusi label — dikerjakan via `_verify_dataset.py` → `dataset/figaro1k/_report_figaro1k.json` (RGB 3-ch, 8-bit, uint8; resolusi 276–1000px).

## 3. Data Augmentation (Spatial Invariance)

- [x] **Random Resized Crop** (scale 0.875–1.0, aspect 3/4–4/3) — solusi utama posisi/skala objek bervariasi.
- [x] Random Horizontal Flip (p=0.5), Rotasi ±10°.
- [ ] Affine ringan (translate ±10%, shear kecil).
- [ ] Fotometri: brightness/contrast ±10%; **hue jitter kecil ±0.02 (HSV)** (tahan AWB, tanpa mematikan makna bleaching).
- [ ] Cutout 2–4 patch kecil (optional).

> Di sisi **inference**: normalisasi & resize SAMA PERSIS dengan training (256→224 + ImageNet) — tanpa augmentasi. Ini wajib agar akurasi train/inference konsisten.

## 4. Integrasi Backend — `CvService.ts`

- [x] Decode gambar (buffer) + auto-orient EXIF → preprocessing pipeline (Node-side: `sharp` resize 256 keep-aspect → center-crop 224 → normalisasi ImageNet NCHW F32).
- [x] Inference via **`onnxruntime-node`** (^1.20.1 ter-resolve 1.29.0): feed tensor float `NCHW 1×3×224×224` → logits → softmax → label + confidence. (**load via `readFileSync` — ONNX single-file, external data di-embed**)

- [ ] Ekstraksi `hair_features` (HSV+GLCM) digabung ke respons `AnalyzeResponse`/konteks.
